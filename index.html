Secure Encryption Platform (Web)

⚠️ Security Warning: This is a demo using AES-256-GCM (standard AES max key size; "AES-4096" isn't standard—using PBKDF2 for key derivation). SHA-512 for password hashing/derivation. For production, use audited libs like libsodium. Client-side E2E encryption. Never use for sensitive data without review. Telegram bot below shares backend.
